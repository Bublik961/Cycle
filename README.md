# Лабораторная работа:  Циклы с предусловием и постусловием

## Автор
Тенц Ангелина (Вариант 7)

## Цель
Изучить использование циклов с предусловием и постусловием в C++.

## Описание
Программа вычисляет остаточное давление в камере с заданным количеством качаний поршневого насоса. Расчет выполняется для двух участков с разными шагами.

## Исходные данные
Объем камеры: 15 л
Начальное давление: 760 мм р.с.
Рабочий объем насоса: 0.6 л
Количестве качаний: 10, 20, 30, 40, 50, 100, 150, 200, 250

## Ожидаемые результаты
Программа выводит таблицу значений остаточного давления.
